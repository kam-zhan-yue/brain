### Service Quote Duplicate Bug
The flow to create a service quote do and charge line item is through the APITable3, which interacts with the API.

The API will call this function every `perform_update`, `perform_create`, `perform_delete`, etc.

```python
ServiceQuoteService.update_lineitem_annual_subtotals(servicequote)
```

In turn, this sets all the annual subtotals to this:
```python
servicelineitem.annual_subtotal = servicelineitem.service_price * servicelineitem.number_of_visits
```

Number of visits is a cached property on the service quote that will respect the supersede map.

However, when we do the duplicate functions from either `duplicate_legacy` or `duplicate`, it will just calculate subtotals like normal. 

This is why when we call servicelineitem.get_annual_subtotal, it is wrong. We just need to change get_annual_subtotal to the actual function
