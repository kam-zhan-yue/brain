The benefit of Tanstack Query is to be able to call the same queries with the same shape and having it cached locally, so that subsequent calls will not re-call.

Then, when refetching, we can refetch the query key generated by the url + fields specified, so that only those places that use the query will be affected.

The idea here is to get rid of everything inside of the `useContext` and have them exist as data hooks. So, all components will have their own `useTask`, their own loading states, etc. In order for them to have the same shape, we need to consolidate that somewhere.

And we can do things like refetching two different queries by refetching two cached keys, etc.
