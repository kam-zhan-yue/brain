Ok resolved.

The signal is being called before `ReportItems` is called. When it is first saved, django will save the model in `super.form_valid()`. This will trigger the signal.

```python
def form_valid(self, form):
	"""If the form is valid, save the associated model."""
	self.object = form.save()
	return super().form_valid(form)
```
