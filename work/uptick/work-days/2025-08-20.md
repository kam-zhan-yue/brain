### Customer Portal Failures
Seems like there is a problem with the customer portal.
- The page title populates when it is RR, but not TSR
- The customisation options populates when it is RR, but not TSR

This is an issue with `useMatch`

```tsx
const { entityId, entityType } = useMatch('/customerportal/:entityType/:entityId/')?.params || {}

const match = useTanstackMatch({
from: '/_authenticated/customerportal/_customerPortalServices/$entityType/$entityId',
shouldThrow: false,
})
console.info(`Entity ID is ${entityId}`)
```

Seems like in `useMatch`, I need to find a way to get the route ID of the current path

Not only that, but wildcards are not accepted in tanstack useMatch

There is another problem with `location.search`

Tanstack is giving
```
?client=1%2F
```

After decoded, it gives
```
?client=1/
```

React Router is 
```
?client=1
```

Needed 
```
  // TSR gives us URL-encoded sequences like %2F that need to be decoded
  const decodedSearch = decodeURIComponent(tanstackLocation.searchStr)
  // We default trailing slashes, but existing RR code doesn't like trailing slashes in our search
  const parsedSearch = decodedSearch.endsWith('/') ? decodedSearch.slice(0, -1) : decodedSearch

  return {
	search: parsedSearch
  }
```
