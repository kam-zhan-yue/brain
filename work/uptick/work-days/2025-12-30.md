## Tanstack Generation
Firstly, what are the current steps in order to generate/modify a route?
- Add a route to routes/
  Remove the boilerplate
- Run mise build:routes
- Add component to route-maps

Tanstack currently writes the template code from a [templates.ts file](https://github.com/TanStack/router/blob/78d626fd56fa7733a4f838d8c2e2ff0546a62a1f/packages/router-generator/src/template.ts#L76)

There are two options to override this:
- Write a bun patch
- Write a ts-morph that will scan the routes folder and remove the components in all the flles
- Then, we need to see what changed. We can snapshot before and after
- For all the file routes that changed, we want to add them to the route map or not

Planned Flow:
1. Scan the route tree to get all of the routes (or check git changelog)
2. Run tsr generate
3. Scan the route tree to see what routes changed
4. For all the routes that changed, change them to the route map
5. Output this
