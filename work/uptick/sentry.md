Go to #team-workforce

Assign things to people who might have caused the bug
1. Check the stack trace
2. Fix yourself (if you know it's going to be easy, 10-15 minutes)
3. Sometimes there's a suspect commit, but it can be unreliable
4. Check file history to see what caused it to regress

### When to Archive
Only if it is a one-off case, happens really rarely, or is considered a non-issue

### When to Resolve
Resolve it after you fix it and merged it.
- Can resolve in Sentry, but should only ever resolve it in slack
- Resolve "In the next release"

### Creating Tickets
When you assign it to yourself or someone else, create a Jira ticket to track it.
