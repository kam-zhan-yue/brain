# Anatis

開発期間：5日間
所要時間数の概：50時間
動作環境：UnityとC#を使用した
開発チーム： 単独開発者

### 自身の担当範囲
3Dモデル、アニメーション、及び音楽はオンラインで入手した素材を使用し、それ以外の部分は全て自身で開発した。なお、開発においてAIは一切使用していない。


### 制作意図の解説
https://itch.io/jam/umgmc-msj-s1-2025
This game was built for the Melbourne Game Maker's Club 2025 S1 Mid Semester Jam, which ran from April 17 to April 23 with the theme 「Spellcasting」.

Anatisは2025年4月17日から4月23日にかけて開催された、University of Melbourne Game Makers' ClubのMid Semester Game Jamで制作した作品である。「Spellcasting」のテーマに、カードを用いて魔法をオンレール型アクションゲームを制作した。

当時は「ザ・ハウス・オブ・ザ・デッド」のようなアーケードオンレール型ゲームに興味をもっていた。また、「Balatro」を遊んでおり、カードを使う際の気持ちよさにも魅力を感じていた。そこで、オンレールゲームの爽快感とカードゲームの戦略性を組み合わせることを目指した。

Anatisにはプレイヤーダンジョン内を自動で移動し、各部屋に獲得したカードを組み合わせながら数秒で攻略方法を判断する。アクション性とパズル性を融合した作品である。

カード操作の気持ちよさにこだわった。Balatroを参考にし、滑らかなアニメーションを実装し、シェーダーやパーティクルエフェクトを用いて状態異常や効果を視覚的に表現することで、操作時の満足感を高めた。

また、ゲームのビジュアル表現にも力を入れた。魔法の演出にはUnityのパーティクルシステムを活用し、雷や炎などのテクスチャを自作してエフェクトを実装した。カードのテクスチャはKritaを用いて手描きで制作し、背景にはライトベイクを適用した。さらに、ディザリングシェーダーを実装することで、レトロな雰囲気を表現した。

20作品が参加したゲームジャムにおいて、1位を獲得した。
