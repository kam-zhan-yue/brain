### Buffer Controls
- `tj` and `tk` to navigate
- `tq` to close

### Telescope
- `<leader>fg` to live grep
- `<C-p>` to search files

### Neotree
- `<C-n>` to toggle file tree
- `<Shift-H>` to show hidden files

### General
- `<Shift-K>` to show type hints
