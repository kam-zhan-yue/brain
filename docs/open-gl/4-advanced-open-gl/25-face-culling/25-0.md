How do we know if a face of an object is not visible from the viewer's point of view? If we imagine any closed shape, each of its faces has two sides. Each side would either face the user or show its back to the user.

Face culling ensures that we only render the faces that are facing the viewer. OpenGL checks all the faces that are front facing towards the viewer and renders those while discarding all the faces that are backfacing. This saves a lot of fragment shader calls. We need to tell OpenGL which of the faces are the front and back. OpenGL uses a trick called the *winding order* of vertex data.
