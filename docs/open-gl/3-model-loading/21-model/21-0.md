Now, we can create a model class that contains multiple meshes, possibly with multiple textures. A house, that contains a wooden balcony, a tower, etc, could be loaded as a single model.

We will load the modal via Assimp and translate it to multiple `Mesh` objects we've created.

```c++
class Model {
public:
  Model(char *path) {
    loadModel(path);
  }
  void draw(Shader &shader) {
    for (unsigned int i = 0; i < meshes.size(); ++i) {
      meshes[i].draw(shader);
    }
  }

private:
  // model data
  vector<Mesh> meshes;
  string directory;
  void loadModel(string path);
  void processNode(aiNode *node, const aiScene *scene);
  Mesh processMesh(aiMesh *mesh, const aiScene *scene);
  vector<Texture> loadMaterialTextures(aiMaterial *mat, aiTextureType type, string typeName);
};
```

The `Model` class contains a vector of `Mesh` objects and requires us to give it a file construction. It loads the file with `loadModel`.
