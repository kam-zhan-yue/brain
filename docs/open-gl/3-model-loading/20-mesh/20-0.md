Once models are loaded, they are stored in Assimp's data structures. We want to transform that data to a format that OpenGL understands so that we can render the objects. We can create a mesh class of our own.

A mesh should have a set of vertices, where each vertex contains a position vector, a normal vector, and a texture coordinate vector. A mesh should also contain indices for indexed drawing, and material data in the form of textures.

```c++
struct Vertex {
	glm::vec3 Position;
	glm::vec3 Normal;
	glm::vec2 TexCoords;
}
```

We also want to organise the texture data in a `Texture` struct. We store the id of the texture and it's type (diffuse or spectular)

```c++
struct Texture {
	unsigned int id;
	string type;
}
```
