The colour of an object is not the colour it actually has, but the colour that is reflected from the object. The colours that aren't absorbed by the object is the colour we perceive of it. White sunlight is a collection of all the visible colours and the objects absorbs a large portion of the colours. It only reflects the colours that represent the object's colour and the combination of those is what we perceive.

The rules of colour reflection apply in computer graphics. When we define a light source in OpenGL, we want to give this light source a colour. If we multiply the light source's colour with an object's colour value, the resulting colour would be the reflected colour of the object (and thus its perceived colour). We would get the resultant colour value as such:


### White Light
In this case, the object absorbs a large potion of the white light, but reflects several red, green, and blue values from its own colour value. We can thus define an object's colour as *the amount of each colour component it reflects from a lightsource*

```c++
glm::vec3 lightColour(1.0f, 1.0f, 1.0f); // white
glm::vec3 toyColour(1.0f, 0.5f, 0.31f);
glm::vec3 result = lightColour * toyColour;
```

### Green Light
If we use a green light, the toy has no red or blue light to absorb and/or reflect. The toy also absorbs half of the light's green value, but also reflects half of the light's green value.

```c++
glm::vec3 lightColour(0.0f, 1.0f, 0.0f); // green
glm::vec3 toyColour(1.0f, 0.5f, 0.31f);
glm::vec3 result = lightColour * toyColour;
// result is (0.0f, 0.5f, 0.0f);
```
