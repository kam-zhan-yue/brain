To use more than one light source in the scene, we want to encapsulate the lightning calculations into GLSL functions.

When using multiple lights in a scene, the approach is usually as follows:
- Have a single colour vector that represents the fragment's output colour
- For each light, the light's contribution to the fragment is added to the output's colour vector. So each light in the scene will calculate its individual impact and contribute to the final output colour.

```glsl
void main() {
	vec3 output = vec3(0.0);
	output += directionalLight();
	for (int i=0; i<numPointLights; ++i) {
		output += pointLight();
	}
	output += spotLight();
	
	FragColor = vec4(output, 1.0);
}
```
