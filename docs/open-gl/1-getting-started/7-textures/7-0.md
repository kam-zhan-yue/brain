In order to achieve realism, we need to have many vertices and colours. This creates considerable overhead, since each model needs a lot more vertices and for each vertex a colour attribute as well.

Textures are 2D images used to add detail to an object. A texture is like a piece of paper with a nice brick image on it neatly folded over your 3D house so it looks like your home has a stone exterior. We can't insert a lot of detail in a single image, but we can give the illusion that the object is detailed without having to specify extra vertices.

In order to map a texture to vertices, we need to tell each vertex which part of the texture it corresponds to. Each vertex should thus have a texture coordinate associated with them that specifies which part of the texture image to sample from.

Fragment interpolation then does the rest for the other fragments.

Texture coordinates range from 0 to 1 in the x and y axes. Retrieving the colour using texture coordinates is called **sampling**. Texture coordinates start at (0, 0) for the lower left corner of a texture image, to (1, 1), the upper right corner.

If we specify three texture coordinates for a triangle, we can do

```c++
float texCoords[] = {
	0.0f, 0.0f, // lower left corner
	0.5f, 1.0f, // top centre corner
	1.0f, 0.0f, // bottom right corner
}
```
