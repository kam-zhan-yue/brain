Make a `.sh` file and input a shebang and echo command.

```bash
#!/bin/bash
echo "Hello World"
```

Then make the script an executable by running

```bash
chmod +x filename.sh
./filename.sh
```

Another way to run the script would be
```bash
bash filename.sh
```

As bash can be used interactively, you could run the following command in your terminal and get the same result. A script allows you to combine multiple commands together
