### Amazon Elastic Block Store (EBS)
Is essentially storage for EC2 instances. It provides scalable block storage resources. You can create and manage the following block storage resources:
- Amazon EBS volumes: Storage volumes that attach to EC2 instances. After you attach a volume to an instance, you can use it in the same way you would use a local hard drive attached to a computer.
- Amazon EBS snapshots: Point-in-time backups of EBS volumes that persist independently from the volume itself. You can create snapshots to back up the data on your Amazon EBS volumes. You can then restore new volumes from those snapshots at any time.
