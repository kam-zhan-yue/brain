Amazon S3 is an object storage service that offers scalability, data availability, security, and performance. Amazon S3 can be used to store and protect any amount of data for a range of use cases, such as data lakes, websites, mobile applications, backup and restore, etc
- You can create buckets and upload stuff using the management console or CLI. The management console is pretty self explanatory
- Using CLI, you can first connect to an C2 instance that has a connection to your AWS account.

```
aws s3 ls
aws s3 mb s3://labbucket-xxxx // make buckeet
aws s3
```

In all AWS Regions, there are at least 3 availability zones. When something is added to an S3 bucket, this is duplicated among all three zones
### Use Cases
- When many users need to access content
- When the data set continues to grow
- When data continues to be updated and read after reading
### Storage Classes
There are different storage classes available depending on how frequent the data is going to be accessed.
- S3 Express One Zone: For data that needs to be accessed frequently. Takes  les than 10 milliseconds to access
- S3 Glacier Deep Archive: For data that doesn't need to be accessed frequently. Takes 12-48 hours to restoreS
- The less frequent you need to access the data, the cheaper it is
S3 Intelligent-Tiering has automatic cost savings for data with unknown or changing access pattern

### S3 Versioning
- Versioning is a means of keeping multiple variants of an object in the same bucket. It can be used to recover from unintended user actions and failures
- After versioning is enabled for a bucket, if S3 receives multiple write requests for the same object simultaneously, it stores all of those objects.
- If you delete an object, S3 inserts a delete marker instead of removing the object permanently. The delete marker becomes the current object version
- If you overwrite an object, it results in a new object version in the bucket, you can always restore the previous version.

### Event Notifications
- S3 event notifications can be used to receive notifications when things happen in the S3 bucket. It can detect things like
	- New object created events
	- Object removal events
	- Restore objet events

#### Lifecycle
- S3 Lifecycle helps you store objects cost effectively throughout their lifecycle by transitioning them to lower-cost storage classes, or, deleting expired objects on your behalf
